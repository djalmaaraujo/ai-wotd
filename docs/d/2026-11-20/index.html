Hy4-flash

Hy4-flash trended because Tencent published its official model card revealing a 220B MoE architecture with 1M context and multimodal input, and AngelSlim immediately released five GGUF quantizations (Q4_K_M, SPARK-4Bit, Q3_K, IQ2-AH) that make the model runnable on high-end local GPUs. The combination of a major Chinese lab's new flagship MoE and ready-to-use quantized artifacts drove simultaneous discussion on Hugging Face and in open-source LLM communities.

Definition

Hy4-flash is Tencent's flagship mixture-of-experts (MoE) large language model, featuring 220 billion total parameters (including a 64B-parameter 'Engram' memory component) but only 12 billion active parameters per forward pass. It accepts both text and images, generates text, and supports a 1-million-token context window. Its 42-layer backbone comprises one dense feed-forward layer and 41 MoE layers, optimizing inference cost through sparse activation. The model is released under a permissive license on Hugging Face with official GGUF quantizations for local deployment via llama.cpp.
