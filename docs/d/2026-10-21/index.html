Inference trended because DeepSeek released DeepInfer, an open-source production inference stack with published performance and economics (155T tokens/day/cluster, $22M/day revenue, 81-day payback), directly challenging proprietary inference platforms. Definition

Inference in AI refers to the process of running a trained model to generate predictions, completions, or embeddings for new inputs. It is the operational phase where models serve real-world requests, distinct from training. Inference systems optimize for latency, throughput, and cost, employing techniques like kv-caching, quantization, batching, and speculative decoding. The term also denotes the serving stack — model loaders, schedulers, and APIs — that powers production applications.

Today in AI

DeepSeek dominated today's AI infrastructure conversation by open-sourcing its production inference stack, DeepInfer, at PyTorch Conference 2026. The system reportedly serves 155 trillion tokens per day per cluster at roughly 80% margins, undercutting closed-source rivals like Fireworks and Baseten. Accompanying releases include deepseek-recipe, a Rust/Python toolkit that normalizes API formats for inference backends, and 3FS, a distributed file system built for both training and inference workloads using RDMA and SSD disaggregation. The PyTorch event also highlighted ecosystem projects vLLM, DeepSpeed, and Ray, signaling continued momentum around open inference tooling.
