Kitten TTS 2

Kitten TTS 2 trended because its GGUF weights were newly published on Hugging Face by Stellon Labs and simultaneously wired into audio.cpp via a dedicated model spec, giving developers immediate access to quantized BF16/Q8/Q4 variants with 48 voices. The dual release — model weights and inference integration — triggered coordinated discussion across the open-source audio community.

Definition

Kitten TTS 2 is a small-footprint, multilingual text-to-speech model developed by KittenML. It uses a MeanFlow decoder and speaker encoders to synthesize speech from text in multiple languages, shipping with 48 built-in voice profiles. The model is distributed as quantized GGUF files (BF16, Q8, Q4) for efficient CPU/GPU inference and is supported by the audio.cpp runtime, enabling local, real-time speech generation without cloud APIs.

Today in AI

Kitten TTS 2, a compact multilingual text-to-speech model from KittenML, gained traction today as developers integrated it into the audio.cpp inference engine and published quantized GGUF weights on Hugging Face. The model, identified by revision f2eee74f, bundles a MeanFlow decoder, speaker encoders, a tokenizer, and 48 pre-built voice profiles. Stellon Labs provided the self-contained GGUF exports under the dignome/kitten_tts2 repository, while 0xShug0 added a model specification (kitten_tts2.json) to audio.cpp enabling BF16, Q8, and Q4 quantization support. The release highlights the growing momentum of lightweight, locally runnable TTS systems that ship with diverse voice libraries and run on consumer hardware without external dependencies.
