computer-use agents

The term trended because Vercel announced a desktop platform that allows any coding agent to drive a user's desktop, directly enabling computer-use agents to perform actions across applications. Simultaneously, MIT Technology Review published an article declaring the arrival of the "agentic web," framing computer-use agents as the realization of Tim Berners-Lee's decades-old vision of autonomous software agents navigating the web on users' behalf.

Definition

Computer-use agents are AI systems that can interact with graphical user interfaces—clicking, typing, scrolling, and navigating applications—much like a human user. Unlike traditional chatbots or code generators, they operate the desktop environment directly, enabling end-to-end task automation such as filling forms, extracting data from legacy software, or orchestrating multi-step workflows across programs. This capability matters because it extends AI beyond text generation into general-purpose computer operation, unlocking automation for tasks without APIs.
