GLB-3D-Coder

GLB-3D-Coder trended today because CCORE published the model on Hugging Face with a clear demo loop — natural-language prompt to runnable Three.js page to GLB asset — targeting a concrete workflow for indie game developers and 3D content creators.

Definition

GLB-3D-Coder is a 4-billion-parameter code generation model fine-tuned from Qwen3.5-4B by the CCORE project. It specializes in converting natural-language descriptions of characters, props, buildings, or environments into self-contained Three.js HTML/JavaScript pages that render a live 3D preview and provide an Export GLB button, enabling direct import into game engines such as Godot. Released under Apache 2.0, it exemplifies the trend toward small, task-specific models that bridge generative AI and real-time 3D asset pipelines.
