Inkling 2 Mini

Inkling 2 Mini trended because the Project Maya community released a highly optimized inference stack (maya-inkling-mini) that runs the 26B looped MoE entirely on a single consumer RTX 3090 at 128 tok/s, and Latent Space's AINews positioned it as the architectural precursor to Z.ai's newly announced GLM 5.4 looped transformer.

Definition

Inkling 2 Mini is a 26-billion-parameter looped mixture-of-experts (MoE) language model developed by Thinking Machines. It uses a recurrent 'looped' architecture where a single set of expert layers is applied iteratively, enabling high parameter efficiency. The model is notable for its deployment via the Project Maya (maya-ik2) engine, which quantizes and batches experts to fit entirely in 24 GB VRAM on an RTX 3090, achieving 128 tokens/second decode with 344K context, image understanding, and tool use. It demonstrates that large MoE models can run locally on consumer hardware without model splitting.
