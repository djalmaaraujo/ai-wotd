PyTorch 2.15

PyTorch 2.15 trended today because Hugging Face released a technical blog post highlighting their extensive upstream contributions to the release's MPS backend, detailing concrete fixes for operator support, performance, and memory issues on Apple Silicon that affect developers running models locally on Macs.

Definition

PyTorch 2.15 is a major release of the PyTorch open-source machine learning framework, shipped in early 2026. Its most prominent improvement is a substantially upgraded Metal Performance Shaders (MPS) backend that enables stable, performant training and inference on Apple Silicon GPUs. The release replaces the previous MPSGraph fallback with dedicated Metal kernels, expanding operator coverage and resolving memory-growth and performance-cliff issues that previously limited Mac viability for serious model development.

Today in AI

Hugging Face's PyTorch team published a detailed account of their contributions to PyTorch 2.15, focusing on the Metal Performance Shaders (MPS) backend for Apple Silicon. The post describes a systematic effort throughout early 2026 to run real-world models from the Hugging Face Hub — spanning language, image, and video tasks — and to fix upstream gaps such as unsupported operations, performance cliffs, and unexpected memory growth. A key technical shift involves replacing MPSGraph with dedicated Metal kernels to expand operator coverage and stability. This work reflects a broader industry push to make Mac hardware a first-class platform for both training and inference, complementing similar vendor-specific optimization efforts across the AI stack.
