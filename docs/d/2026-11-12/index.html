Gemini Decision 1

Gemini Decision 1 trended because Google surprised the industry by shipping the first production-ready decision model from a major lab, announcing it alongside a dedicated Decisions API with concrete pricing ($0.10/M input), latency (~200 ms), and throughput (1,000 questions per call) metrics. The launch was covered simultaneously by Google's official blog and prominent AI newsletters, framing it as a competitive milestone against Anthropic.

Definition

Gemini Decision 1 (gemini-decision-1) is a calibrated multimodal model from Google designed for fast, closed-set decision tasks. Unlike generative LLMs that produce open-ended text, it takes a single multimodal input (text, image, audio, video, or PDF up to 256K tokens) and a set of up to 1,000 independent questions, then returns structured decisions for each — such as tool selection, policy compliance, model routing, or context relevance scores. It is served through the Gemini Decisions API in Google AI Studio, offering deterministic, low-latency (~200 ms) inference at a fixed price per million input tokens. The model represents a new class of "decision models" optimized for agentic control flow rather than content generation.

Today in AI

Google launched Gemini Decision 1, a calibrated multimodal decision model accessible via the new Gemini Decisions API in Google AI Studio. The model evaluates up to 1,000 independent questions in a single pass across text, images, audio, video, and PDFs (256K token context) with roughly 200 ms end-to-end latency at $0.10 per million input tokens. Sundar Pichai and Logan Kilpatrick announced the release, positioning it as the first production-grade decision model from a major lab — beating Anthropic to market. The API targets bounded-choice tasks such as tool selection, policy checks, model routing, and context grading, returning structured decisions rather than generated text. The launch coincides with broader industry focus on decision models as a new primitive for agentic workflows, and developers are already comparing it to the iPhone-era shift in AI device paradigms.
