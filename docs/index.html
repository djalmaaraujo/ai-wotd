PhotoCraft

PhotoCraft trended today because ArtCraft founder Brandon Thomas demoed the Rust-based Photoshop clone at the AI Engineer Code Summit in San Francisco, framing it as a manifesto for AI-era open-source software that replicates proprietary creative tools with native performance and full file-format parity.

Definition

PhotoCraft is an open-source, cross-platform raster graphics editor developed by ArtCraft as a drop-in replacement for Adobe Photoshop. Built in Rust with a native compositor targeting Metal, Vulkan, DirectX 12, and WebGPU, it replicates Photoshop's UI, shortcuts, layer system, adjustment layers, filters, smart objects, and PSD/PSB file format with byte-for-byte round-trip accuracy. It runs offline, requires no web runtime, and is positioned as the first release in ArtCraft's broader strategy to recreate proprietary creative software as community-owned, AI-extensible alternatives.

Today in AI

ArtCraft, a fledgling company founded by Brandon Thomas, presented its ambitious open-source strategy at the AI Engineer Code Summit in San Francisco. The centerpiece is PhotoCraft, a Photoshop-compatible image editor written entirely in Rust that runs natively on Metal, Vulkan, DirectX 12, and WebGPU without Electron. The application achieves near-perfect PSD/PSB round-trip fidelity — 134 of 135 real-world test files match byte-for-byte — and replicates Photoshop's menus, shortcuts, panels, and tools including 16 adjustment layers, 70-plus live-preview filters, and smart objects. ArtCraft has released 17 open-source clones of popular software tools to date, and Thomas signaled intentions to extend the approach beyond imaging, having already replicated Adobe Acrobat. The project's public parity tracker on GitHub documents ongoing compatibility work against Photoshop 26.6.1.
