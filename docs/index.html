Gemma-4-31B-Humanlike-Chat

Gemma-4-31B-Humanlike-Chat trended because LessThanThreeAI published two Hugging Face repositories (BF16 and GGUF) on the same day, offering a drop-in, no-system-prompt alternative to Google's official Gemma-4-31B-it that immediately attracted attention for its 'humanlike' chat style and tool-use retention. The launch sparked discussion around quantization options and KL-divergence training details, amplifying its visibility in open-model circles.

Definition

Gemma-4-31B-Humanlike-Chat is a community fine-tune of Google's Gemma-4-31B-it (a 31-billion-parameter open-weight language model) created by the Hugging Face user LessThanThreeAI. It is optimized for natural, concise conversation without requiring a system prompt, while preserving the base model's ability to perform tool calls and structured generation. The model is distributed in both BF16 (for vLLM, SGLang, Transformers) and GGUF (for llama.cpp) formats, making it runnable on consumer and datacenter GPUs.
