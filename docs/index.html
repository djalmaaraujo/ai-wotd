Trainium3

Trainium3 trended because Hugging Face published a detailed benchmark of the AWS chip, including access to a trn3.48xlarge instance with 64 NeuronCores. The post demonstrated end-to-end video generation using Lightricks' LTX-2.5, reporting 22 to 23 seconds per 10-second clip with sound. The timing and specificity of the infrastructure test drove attention to the new accelerator.

Definition

Trainium3 is Amazon Web Services' third-generation AI accelerator chip, delivered through EC2 Trn3 instances such as trn3.48xlarge with 64 NeuronCores. It is designed for training and inference of large machine learning models and is programmed using the AWS Neuron SDK. In the AI industry, Trainium3 serves as a non-GPU cloud alternative for developers building and deploying generative models, including video and audio systems.

Today in AI

Hugging Face researchers tested AWS Trainium3 chips by generating video with Lightricks' LTX-2.5 model. The team accessed a trn3.48xlarge instance with 64 NeuronCores through a partnership with AWS, spending most of a month adapting models to the hardware. In a final experiment, a 10-second video clip with sound took 22 to 23 seconds to generate once models were loaded. The work illustrates how AI infrastructure providers and model developers are collaborating to evaluate new accelerators outside traditional GPU environments. Engineers reported that the system runs on AWS Neuron software, and that loading weights takes significant setup time before inference. The second phase of testing focused on audio-video synchronization, while a trigger in the benchmark script initiated clip generation. The experiment is part of a broader effort to determine whether non-NVIDIA silicon can support generative video workloads at scale.
